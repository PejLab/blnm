# BLNMixture R Manual

## Overview

This mini-package provides an R port of the MATLAB `BLNMixture` class for fitting mixtures of Binomial-Logit-Normal (BLN) components with an optional fixed-weight uniform noise component. The workflow mirrors the MATLAB demo: simulate binomial counts from a mixture, fit the model via expectation-maximization (EM), evaluate likelihoods, draw new samples, and generate diagnostic plots.

Key files:

- `R/BLNMixture.R` – Core implementation (fitting, pdf evaluation, sampling, helpers).
- `R/BLNMixture_Demo.R` – End-to-end demonstration with diagnostic plots.
- `plots/` – Output directory for figures generated by the demo.

## Requirements & Setup

The code relies only on base R and the `stats` package (no external dependencies). To run the demo:

```sh
Rscript R/BLNMixture_Demo.R
```

Running the demo populates `plots/` and prints fit diagnostics to the console.

## Core API (`R/BLNMixture.R`)

### `bln_mixture_fit(X, Xc, K, ...)`

Fits a BLN mixture with `K` components and an optional uniform noise channel.

Arguments (selected):
- `X`, `Xc`: Success and failure counts (numeric vectors). Each observation corresponds to binomial trials with total `n_i = X_i + Xc_i`.
- `K`: Number of BLN components (integer > 0).
- `max_iter` (default 200): EM iterations per restart.
- `tol` (1e-6): Relative log-likelihood tolerance for convergence.
- `quad_nodes` (30): Gauss–Hermite quadrature nodes for approximating the BLN likelihood.
- `restarts` (3): Number of random restarts; the best log-likelihood is retained.
- `display` (`"off"` or `"iter"`): Verbosity of the EM loop.
- `init` (list): Optional initial values for `mu`, `sigma`, `pi`.
- `use_bfgs` (TRUE): Use BFGS (`optim` method = `"BFGS"`) for component updates; falls back to Nelder–Mead when `FALSE`.
- `uniform_weight` (1e-3): Fixed weight `w0` of the uniform noise component (clamped to [0, 0.5]).
- `shared_sigma` (FALSE): If `TRUE`, enforces a common standard deviation across components.
- `random_seed`: Optional seed for reproducibility.

Returns an object of class `"BLNMixture"` containing:
- `K`, `mu`, `sigma`, `pi`, `uniform_weight`, `QuadNodes`.
- Fit diagnostics: `loglik`, `iters`, `converged`, `details`.
- Responsibilities (`resp`) and MAP labels (`labels`).

### `bln_mixture_pdf(object, x, n, log = FALSE)`

Evaluates the mixture pmf at observed counts `x` with totals `n`. Set `log = TRUE` for log-pmf. Uses cached quadrature nodes for efficiency.

### `bln_mixture_rnd(object, n)`

Simulates counts from the fitted mixture:
- `n`: Vector (or scalar) of binomial totals.
- Returns a list with `x` (successes), `xc` (failures), and `z` (component labels, where `K+1` denotes the uniform component).

### `print.BLNMixture(object)`

S3 print method summarizing key fields.

## Fit Workflow

1. **Prepare counts**: Provide success/failure vectors (`X`, `Xc`). Non-finite or negative values are filtered automatically.
2. **Choose options**: Select `K`, whether to share `sigma`, number of restarts, etc. Use `init` to seed parameters when deterministic starting points are desired.
3. **Run EM**: Call `bln_mixture_fit(...)`. With `display = "iter"`, the EM progress is printed.
4. **Inspect results**:
   - `fit$mu`, `fit$sigma`, `fit$pi`: Component parameters.
   - `fit$labels`: MAP assignments (`1..K` for BLN components, `K+1` for uniform).
   - `fit$resp`: Posterior responsibilities (rows sum to 1).
   - `fit$converged`: Logical indicator; `fit$loglik` provides the final log-likelihood.
5. **Evaluate model**: Use `bln_mixture_pdf` to evaluate pmf/log-pmf on data or candidate points.
6. **Simulate**: Use `bln_mixture_rnd` with `fit` to generate new data under the fitted mixture.

## Demo (`R/BLNMixture_Demo.R`)

The demo script:
- Simulates data from a 3-component BLN mixture with a small uniform tail.
- Injects random outliers to ensure the uniform channel is exercised.
- Fits the mixture twice (free vs. shared `sigma`).
- Prints convergence statistics and parameter comparisons.
- Generates diagnostic plots in `plots/`:
  - `fraction_vs_labels.png`: Observed success fraction (`x/n`) vs. MAP labels.
  - `label_counts.png`: Component assignment histogram.
  - `mu_comparison.png`, `sigma_comparison.png`: True vs. estimated parameters.
  - `counts_scatter_overlay.png`: Square-aspect scatter of raw counts (`x` vs. `xc`) with true and inferred component directions overlaid.
  - `shared_sigma_params.png`: Component means for the shared-sigma fit vs. ground truth.

The script automatically adjusts the working directory to its own location, making it safe to invoke from the project root or other directories.

## Customization Tips

- **Uniform Weight**: Tune `uniform_weight` if you expect heavier or lighter outliers.
- **Quadrature Nodes**: Increase `quad_nodes` for higher accuracy when components have small `sigma`. Expect longer runtimes.
- **Restarts**: Increase `restarts` for complex datasets to avoid poor local optima.
- **Initialization**: Provide `init` to stabilize EM on challenging datasets. `init$sigma` may be scalar (when `shared_sigma = TRUE`) or a length-`K` vector.
- **Optimizer Choice**: Set `use_bfgs = FALSE` to use derivative-free Nelder–Mead if BFGS struggles; note that gradients are analytically available when BFGS is enabled.

## Troubleshooting

- **“No valid observations after filtering.”** – Ensure `X` and `Xc` are numeric and non-negative; remove missing values.
- **Slow convergence** – Increase `tol`, allow more iterations, or provide better initial values.
- **Divergent parameters** – Check for components collapsing to extreme logits (`mu` very large in magnitude) when data lack support; constraining or regularizing `sigma` via `shared_sigma = TRUE` can help.
- **Empty plots/zero counts** – Confirm the demo finished successfully and `plots/` exists. Delete the directory if you need a clean rerun; it is recreated automatically.
